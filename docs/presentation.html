UniGraph : Problématique & Objectifs

Limites du Relationnel (SQL)
  • Schémas rigides difficiles à faire évoluer sans migration lourde.
  • Silos de données et absence d'interopérabilité sémantique.
  • Incapacité à déduire de nouvelles connaissances sans coder des règles procédurales applicatives.
La Réponse UniGraph
  • Modélisation sémantique ouverte : Standard W3C RDF/RDFS et intégration du vocabulaire FOAF.
  • Raisonnement déductif formel : Clôture sémantique RDFS pour inférer automatiquement de nouveaux faits.
  • Interopérabilité totale : Requêtage SPARQL 1.1 et API REST JSON.
Périmètre académique : Modélisation complète d'une université (départements, programmes, cours, enseignants, étudiants, inscriptions) avec traçabilité intégrale vers le jeu de données relationnel source.

Pipeline d'Exécution
1. Inspection & Validation : Intégrité référentielle 100% vérifiée.
2. Conversion RDFLib : Génération de 15 621 triplets bruts dans unigraph.ttl avec unigraph:sourceId.
3. Clôture Déductive RDFS : Raisonneur OWL-RL produisant 25 112 triplets (+9 491 inférés).
4. Exposition : SPARQLService + Flask REST API (10 routes).
