Aperçu du Schéma Ontologique
Points Forts du Projet
  • Intégrité Relationnelle :
    Conversion fidèle de 30 tables CSV avec traçabilité unigraph:sourceId.
  • Standard W3C FOAF :
    Réutilisation de foaf:Person et foaf:Organization via rdfs:subClassOf.
  • Inférence RDFS Prouvée :
    Règles rdfs7 (héritage de sous-propriétés) et rdfs9 (propagation de sous-classes).
  • API REST Robuste :
    10+ endpoints JSON conformes, gestion des statuts HTTP et support CORS.
Les requêtes SPARQL pré-enregistrées et le moteur de raisonnement sont directement exécutables via les onglets dédiés.

Documentation des Points d'Accès API REST

Tous les points de terminaison retournent du JSON propre avec statuts HTTP et gestion d'erreurs normalisée.

Méthode Route Description Paramètres Action
GET /api/status État de santé du système et métriques globales du graphe. Aucun
GET /api/ontology Classes, propriétés, hiérarchies et axiomes RDFS. Aucun
GET /api/students Liste des étudiants avec programmes et conseillers. ?limit=50&status=...
GET /api/instructors Liste des enseignants, départements et salaires. ?department=...&rank=...
GET /api/departments Liste des 14 départements universitaires avec budgets. Aucun
GET /api/programs Liste des 40 programmes par niveau de diplôme et département. ?limit=20&department=...
GET /api/courses Liste des cours offerts et départements de rattachement. ?limit=50&department=...
GET /api/sections Sections de cours, enseignants et semestres. Aucun
GET /api/enrollments Inscriptions des étudiants aux sections et notes obtenues. ?limit=50
GET /api/sparql/queries Liste des requêtes SPARQL pré-configurées. Aucun
POST /api/sparql/execute Exécute une requête SPARQL personnalisée ou par ID. Body JSON : {"query": "...", "use_inferred": bool}
GET /api/inference/demo Démonstrations détaillées du raisonneur avec statistiques avant/après. Aucun
